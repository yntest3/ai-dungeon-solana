# ⚔️ AIダンジョン冒険 — Solana Devnet Edition

選択ひとつで展開が変わる、ブラウザで遊べるダンジョン冒険ゲームです。

- **AIが物語を生成**：Claude API がプレイヤーの行動に応じて、イベント・敵・宝物・物語を毎ターン生成します。
- **オフラインでも遊べる**：API キーが未設定のとき、または通信エラーやタイムアウトが起きたときは、あらかじめ用意したイベント（宝箱・泉・商人・罠・祭壇・戦闘・ボスなど）に自動で切り替わります。
- **リザルト表示**：クリア／ゲームオーバー、スコア、ランク、到達階層、獲得アイテムを表示します。
- **Solana Devnet に記録**：Phantom ウォレットを接続すると、冒険の結果を Memo プログラムのトランザクションとして Devnet に書き込めます。自分の過去の記録も一覧表示できます。

ゲームは `index.html` の 1 ファイルだけで動きます（ビルド不要）。

---

## 起動方法

Phantom はページが `http://` または `https://` で開かれているときだけウォレットを注入します。そのため、**ローカルサーバー経由で開いてください**。`index.html` をダブルクリックして `file://` で開いた場合、ゲームは遊べますが、ウォレット接続はできません。

以下のどれか 1 つを使って、`index.html` があるフォルダでサーバーを起動します。

```bash
# Python 3
python -m http.server 8000

# Node.js
npx serve -l 8000 .
```

ブラウザで <http://localhost:8000> を開きます。

> 動作には、インターネットから Solana web3.js（unpkg CDN）を読み込める環境が必要です。読み込めない場合も、ゲームは内蔵イベントで遊べます。ウォレット機能だけが使えなくなります。

## AI（Claude API）を有効にする

1. 画面右上の **⚙️ 設定** を開きます。
2. 「AI（Claude API）で物語を生成する」にチェックを入れ、Anthropic の API キー（`sk-ant-...`）を入力します。
3. モデルを選びます。

   | モデル | 特徴 |
   | --- | --- |
   | `claude-opus-5-5` | 既定。物語の品質が最も高い |
   | `claude-sonnet-5-5` | 品質と速度のバランス型 |
   | `claude-haiku-5-5` | 最速・最安 |

4. 「保存して閉じる」を押すと、ヘッダーのバッジが `🤖 AI: <モデル名>` に変わります。

### 補足

- AI の応答は、構造化出力（JSON Schema）で決まった形式に固定しています。HP・ゴールド・アイテム性能・攻撃力／防御力の上限など、数値はゲーム側で範囲内に収めるため、AI が極端な値を返してもバランスは崩れません。
- AI がエラーを返したとき、90 秒以内に応答がないとき、または応答を拒否したときは、そのターンだけ内蔵イベントで処理します。次のターンからは再び AI を使います。
- **API キーはブラウザから直接 Anthropic API に送られます**（`anthropic-dangerous-direct-browser-access` ヘッダーを使用）。自分の PC で遊ぶことを想定した仕組みです。
  - ゲームを公開サイトとして配信する場合は、キーを埋め込まないでください。代わりにサーバー側にプロキシを用意し、設定の「API エンドポイント」にそのプロキシの URL を指定してください。
  - 「API キーを保存する」にチェックを入れたときだけ、キーを `localStorage` に保存します。

## Solana Devnet に実績を記録する

### 準備（初回のみ）

1. ブラウザに [Phantom](https://phantom.app/) 拡張機能をインストールし、ウォレットを作成します。
2. Devnet SOL（無料・テスト用）を入手します。次のどちらかの方法があります。
   - ゲーム画面左の **💧 1 SOL エアドロップ** ボタンを押す
   - レート制限で失敗した場合は、<https://faucet.solana.com/> で自分のアドレスに Devnet SOL を送る

   記録 1 回の手数料は約 0.000005 SOL です。
3. （任意）残高を Phantom 上でも確認したい場合は、Phantom の「設定 → 開発者設定 → テストネットモード」をオンにし、Solana Devnet を選びます。

### 記録の流れ

1. 右上の **👻 Phantom接続** を押し、接続を承認します。
2. 冒険をクリアする（またはゲームオーバーになる）と、リザルト画面が開きます。
3. **📝 Devnetに記録する** を押し、Phantom で署名します。
4. 完了すると Solana Explorer（Devnet）へのリンクが表示され、トランザクションの中身を確認できます。

ヘッダーの **📜 記録** を押すと、接続中のアドレスで記録した冒険を Devnet から読み込んで一覧表示します。

### 記録される内容

[SPL Memo プログラム](https://spl.solana.com/memo)（`MemoSq4gqABAXKb96qnH8TysNcWxMyWCqXgDLGmfcHr`）に、次のような JSON を書き込みます。

```json
{"app":"AIDungeon","v":1,"result":"CLEAR","score":2350,"rank":"A","floor":"5/5","turns":31,"gold":420,
 "items":["深淵の王冠","炎の魔剣","月光の宝珠"],"ai":true,"log":"3f9a1c0e5b7d2a64","ts":1792540800}
```

- `log` は、冒険ログ全体の SHA-256 ハッシュの先頭 8 バイトです。
- Phantom には署名だけを依頼し、送信はゲーム側から Devnet の RPC に対して行います。そのため、Phantom のネットワーク設定に関係なく、記録先は必ず Devnet になります。
- RPC の URL は設定画面で変更できます。既定は `https://api.devnet.solana.com` です。

## 遊び方

- 各シーンで 3〜4 個の選択肢から行動を選びます。同じ場面でも、選んだ行動によって結果や次の展開が変わります。
- 1 階層は 3 部屋です。最下層には迷宮の主（ボス）がいて、倒すとクリアになります。ダンジョンの深さは設定で 3 階層か 5 階層を選べます。
- 戦闘の行動は 4 種類です。
  - 攻撃
  - 防御：被ダメージを半減する
  - 渾身の一撃：当たれば 2 倍ダメージ、外れると無防備になる
  - 逃走：ボス戦では使えない
- インベントリの回復アイテムは、クリックするといつでも使えます。武器と防具は、手に入れた時点で攻撃力・防御力に加算されます。
- スコアは、所持ゴールド＋アイテムの価値＋到達階層×100（クリアした場合はさらにボーナス）で計算します。ランクは S〜D です。
